# React + Vite Figma Assignment Submission - React Application for Consulting Website project

A modern and responsive **Consulting Website** built using **React.js**, based on a provided Figma design. The project focuses on converting the UI/UX design into reusable React components while maintaining the visual structure, responsiveness, and overall user experience of the original design.

## 📌 Project Overview

This project was developed as a **Figma-to-React implementation assignment**. The objective was to transform the provided Figma design into a functional React website with reusable components and a clean project structure.

The website represents a consulting/business platform that provides business growth, protection, performance, and other consulting-related services.

---

## 🚀 Features

* Responsive consulting website
* Figma design converted into React components
* Reusable and modular components
* Responsive layout for different screen sizes
* Navigation header
* Hero section with CTA
* Business growth and protection sections
* Customer/user feedback section
* Application benefits section
* Email subscription section
* Business growth CTA section
* Footer with useful links and resources

# ⚙️ Installation & Setup

## 1. Clone the repository

```bash
git clone <your-github-repository-url>
```

## 2. Navigate to the project

```bash
cd consulting-website
```

## 3. Install dependencies

```bash
npm install
```

## 4. Start the development server

```bash
npm run dev
```

The application will be available at the local development URL provided by Vite, usually:

```text
http://localhost:5173
```

---

# 🖥️ Build for Production

To create a production build:

```bash
npm run build
```

To preview the production build:

```bash
npm run preview
```
